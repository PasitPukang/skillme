A comprehensive collection of AI Agent Skills for Google Antigravity and Claude Code.

## Overview
This repository contains **1,480+ specialized skills** across various domains including:
- Software Engineering & Architecture
- DevOps, Cloud & Security (AWS, Azure, GCP, Kubernetes)
- AI / Machine Learning & Data Engineering
- Frontend, Backend, Mobile (React, Vue, Next.js, Flutter, SwiftUI, Android, etc.)
- Business, Marketing, SEO & Product Management
- Workflow Automation & Integrations

## Structure
- `skills/`: Contains individual skill directories, each with a `SKILL.md` instruction file and associated resources/scripts.
